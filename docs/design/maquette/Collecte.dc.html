États de synchronisation — Collecteur

Icône + texte, jamais la couleur seule · aria-live sur la pastille et les barres. La file locale n'est jamais effacée à la déconnexion tant qu'il reste des déclarations non envoyées. Session de 24 h sans renouvellement : au-delà, l'envoi exige une reconnexion. Chaque déclaration est rattachée à l'email du collecteur qui l'a saisie : si un autre compte se connecte, la file n'est pas envoyée (voir Transverses). Bandeau « Connexion rétablie » : voir Transverses.
